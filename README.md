# SmartHire

SmartHire is a full-stack recruitment and job management system that connects candidates and recruiters through a modern web application.

## 🚀 Project Overview

SmartHire allows:

- Candidates to browse available jobs
- Candidates to search and filter jobs
- Candidates to apply for jobs
- Candidates to track their applications
- Recruiters to create and manage jobs
- Recruiters to view applicants
- Recruiters to update application statuses
- Secure authentication using JWT
- Role-based access for Candidates and Recruiters
